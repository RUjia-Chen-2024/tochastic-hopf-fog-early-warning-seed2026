# 结果版本与随机流对照

这份目录以 seed-2026 为唯一当前结果版本。所有主模型使用相同的检查点、数据划分、周期标签、1T 历史、5 秒模拟、128 条轨迹、2 秒主事件窗、严格 `risk > 0.80` 和连续两次确认。

论文保留两条用途不同的 seed-2026 评价流：

- **主评价 / 噪声对照**：batch size 32，主事件窗下完整模型 84/91、160 次报警、中位提前量 0.680 秒；零扩散为 83/91、302 次、1.295 秒。噪声对照复用主评价的 128 条学习噪声路径。
- **训练消融 / 参数回放**：batch size 16 的独立配对重放，完整模型参照为 83/91、166 次报警、0.685 秒。无事件损失、未来常系数、直接风险 MLP 以及 beta、frequency、sigma 的固定干预都以此流为参照。

两条流的科学参数一致，差异来自两次不同的 Monte Carlo 路径流和批处理设置。它们不是同一批随机轨迹，所以完整模型数字不应强行相等；每张表必须保留 `evaluation_stream`。论文方法部分也将主评价和 batch-16 消融回放分开报告。

此前 seed-20261027 的噪声结果（学习噪声 84/91、166 次、0.670 秒）仅保存在 `results/legacy_seed20261027/` 作为历史记录，不属于当前主结果，也不应与 seed-2026 的零噪声行配对。

另请区分：固定 `sigma(s)=sigma(0)` 是**保持噪声存在**、只冻结其时间变化；只有 `sigma=0` 才是关闭扩散。
